### 1.2 修改文件

#### `Agent/CustomerAgent/custom/customer_agent.py`

**新增节点方法**:

| 方法 | 功能 | 输入状态 | 输出状态 |
|------|------|----------|----------|
| `node_router` | 意图路由（三级漏斗） | user_query | current_intent, is_human_needed |
| `node_retriever` | 双轨知识检索 | current_intent, goods_id | knowledge_context |
| `node_generator` | SOP 回复生成 | knowledge_context, user_query | final_response |
| `node_human_fallback` | 转人工执行 | is_human_needed | final_response, 人工锁 |

**图工作流**:

```
START → node_router → [node_human_fallback | node_retriever]
node_retriever → node_generator → END
node_human_fallback → END
```

**关键代码片段**:

```python
def _build_graph(self):
    builder = StateGraph(CustomerServiceState)
    
    builder.add_node(NodeName.ROUTER, self.node_router)
    builder.add_node(NodeName.RETRIEVER, self.node_retriever)
    builder.add_node(NodeName.GENERATOR, self.node_generator)
    builder.add_node(NodeName.HUMAN_FALLBACK, self.node_human_fallback)
    
    builder.set_entry_point(NodeName.ROUTER)
    
    builder.add_conditional_edges(
        NodeName.ROUTER,
        self._route_by_intent,
        {"human": NodeName.HUMAN_FALLBACK, "auto": NodeName.RETRIEVER}
    )
    
    builder.add_edge(NodeName.RETRIEVER, NodeName.GENERATOR)
    builder.add_edge(NodeName.GENERATOR, END)
    builder.add_edge(NodeName.HUMAN_FALLBACK, END)
    
    return builder.compile(checkpointer=self._checkpointer)
```

```python
        )
```

```python
def _simple_refine(self, raw_text: str) -> Dict[str, str]:
    """简单规则改写（降级方案）"""
    keyword_to_question = {
        "漏液": "漏液怎么办？",
        "破损": "破损怎么办？",
        "少件": "少件怎么办？",
        "发错": "发错货怎么办？",
        "退货": "如何退货？",
        "退款": "如何退款？",
        "换货": "如何换货？",
        "发票": "如何开发票？",
        "物流": "物流问题怎么处理？",
        "快递": "快递问题怎么处理？",
    }
    
    for keyword, question in keyword_to_question.items():
        if keyword in raw_text:
            answer = raw_text.replace(keyword, "", 1).strip()
            if not answer:
                answer = raw_text
            return {"question": question, "answer": answer}
    
    # 无法匹配时，使用通用格式
    return {
        "question": f"{raw_text[:10]}怎么处理？",
        "answer": raw_text,
    }
```

```python
        else:
            # 回退到传统检索
```

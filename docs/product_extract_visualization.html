商品结构化抽取链路可视化

这版的核心不是给每个个例写硬编码，而是让本地 LLM 做主抽取；规则层只承担通用的输入归一化、格式清洗、证据校验和少量高置信兜底。

一、整体链路

1. 输入归一化

把标题、价格、销量、规格、详情文本合并成 product_text。

2. LLM 主抽取

调用本地 customer-service:latest，要求输出字段 JSON。

3. JSON 修复

去掉 markdown 代码块，必要时从回复中截取 JSON 对象。

4. 证据校验

字段必须有 evidence，或字段值本身能在原始文本中找到。

5. 通用兜底

只补高确定字段：分类路径末级、规格列表、使用时长、年龄等。

6. 入库/向量

写入 attribute_json，再按字段写 Qdrant。

回答注释：我不把“赠品”作为核心设计。赠品只是某些样本里的脏数据，当前方案应围绕通用字段结构化：LLM 主抽取 + evidence 校验 + 通用规则兜底。规则层不是替代 LLM，而是防止本地模型输出空字段、错 JSON、无证据字段。

二、规则抽取的真实代码实现

下面不是伪代码，是当前 database/product_sync.py 里的关键实现逻辑，省略了无关日志和异常处理。

1. 输入归一化：构建 LLM 输入和证据校验文本

def _build_product_extract_text(self, list_product, detail_product):
    parts = [
        f"商品标题: {list_product.get('goods_name') or ''}",
        f"商品价格: {list_product.get('price') or ''}",
        f"已售数量: {list_product.get('sold_quantity') or ''}",
    ]

    specs = detail_product.get("specifications", []) or []
    if specs:
        parts.append(f"规格列表: {json.dumps(specs, ensure_ascii=False)}")

    raw_text = (
        detail_product.get("raw_text")
        or detail_product.get("extra_text")
        or detail_product.get("extracted_content")
    )
    if raw_text:
        parts.append(f"详情文本: {raw_text}")

    return "\n".join(str(part) for part in parts if part)

2. 规则兜底：只做通用高置信字段，不处理个例

def _extract_attributes_by_rules(self, list_product, detail_product):
    attrs = dict(DEFAULT_PRODUCT_ATTRIBUTES)
    sources = {}
    goods_name = str(list_product.get("goods_name") or "")
    specs = detail_product.get("specifications", []) or []
    text = f"{goods_name}\n{json.dumps(specs, ensure_ascii=False)}\n{extra_text}"

    # A. 主类目：优先用商品分类路径末级，避免上级路径词污染。
    category_text = ""
    for spec in specs:
        if isinstance(spec, dict):
            for key, value in spec.items():
                if "商品分类" in str(key):
                    category_text = str(value)
                    break

    category_leaf = category_text.split(">")[-1] if category_text else ""
    category_from_path = [
        ("防晒霜", ("防晒霜", "防晒")),
        ("素颜霜", ("素颜霜", "面部素颜霜")),
        ("湿敷棉", ("湿敷棉", "化妆棉", "棉片")),
        ("洗脸巾", ("洗脸巾", "棉柔巾", "柔纸巾")),
        ("卸妆水", ("卸妆水", "卸妆乳")),
        ("化妆刷", ("化妆刷",)),
        ("洗面奶", ("洗面奶", "洁面乳", "洁面")),
        ("香水", ("香水", "香氛")),
    ]
    for category, terms in category_from_path:
        if any(term in category_leaf for term in terms):
            self._set_attr(attrs, sources, "category", category, "rule", 0.98, category_text)
            break

    # B. SKU：读取所有款式/规格值，清洗成数组。
    sku_options = []
    for spec in specs:
        if not isinstance(spec, dict):
            continue
        for key, value in spec.items():
            if "款式" not in str(key) and "规格" not in str(key):
                continue
            option = str(value).strip()
            if option:
                sku_options.append(option)
    if sku_options:
        self._set_attr(attrs, sources, "sku_options", sku_options, "rule", 0.9, "；".join(sku_options[:5]))

    # C. 高频自然语言兜底。
    duration_match = re.search(r"(...可用...天|周|个月|月)", text)
    if duration_match:
        self._set_attr(attrs, sources, "usage_duration", duration_match.group(1), "rule", 0.9, duration_match.group(1))

    age_match = re.search(r"(\d+\s*岁以上|儿童|婴儿|宝宝|成人|孕妇|敏感肌)", text)
    if age_match:
        self._set_attr(attrs, sources, "suitable_age", age_match.group(0), "rule", 0.85, age_match.group(0))

    return attrs, sources

3. LLM 输出校验：不是模型说了就入库

def _validate_llm_attribute_payload(self, data, product_text):
    attrs = {}
    sources = {}
    rejected = {}

    for key, item in data.items():
        if key not in PRODUCT_LLM_FIELDS or not isinstance(item, dict):
            continue

        value = self._coerce_attr_value(key, item.get("value"))
        confidence = float(item.get("confidence") or 0)
        evidence = str(item.get("evidence") or "").strip()

        if value in (None, "", []) or confidence < 0.55:
            continue

        value_evidence_ok = (
            any(str(v).strip() in product_text for v in value)
            if isinstance(value, list)
            else str(value).strip() in product_text
        )

        if not self._evidence_in_text(evidence, product_text) and not value_evidence_ok:
            rejected[key] = {"value": value, "reason": "evidence_not_found"}
            continue

        attrs[key] = value
        sources[key] = self._source("llm", confidence, evidence)

    return attrs, sources, rejected

4. 合并策略：LLM-first，但关键结构字段规则兜底

def _merge_llm_first_attributes(self, llm_attrs, llm_sources, rule_attrs, rule_sources):
    attrs = dict(DEFAULT_PRODUCT_ATTRIBUTES)
    sources = {}

    for key in attrs:
        llm_value = llm_attrs.get(key)
        rule_value = rule_attrs.get(key)
        llm_conf = (llm_sources.get(key) or {}).get("confidence", 0)
        rule_conf = (rule_sources.get(key) or {}).get("confidence", 0)

        if key in {"category", "sku_options", "sku_summary"} and rule_value not in (None, "", []) and rule_conf >= 0.75:
            attrs[key] = rule_value
            sources[key] = rule_sources[key]
        elif llm_value not in (None, "", []) and llm_conf >= 0.55:
            attrs[key] = llm_value
            sources[key] = llm_sources[key]
        elif rule_value not in (None, "", []) and rule_conf >= 0.75:
            attrs[key] = rule_value
            sources[key] = rule_sources[key]
        else:
            sources[key] = self._source("missing", 0.0, "")

    self._normalize_final_attributes(attrs, sources)
    return attrs, sources

三、为什么这不是“硬编码赠品方案”

用户关心点现在的处理原因
赠品个例 不作为核心规则展示，也不作为系统设计重点。 你的判断是对的，赠品在商品信息里不是主问题，不能围绕个例设计主链路。
商品类目 用“商品分类路径末级 + 类目归一化”做通用兜底。 解决上级路径词污染，例如“彩妆/香水/美妆工具 > 美容工具 > 湿敷棉”。
商品属性 优先让 LLM 抽取，但必须通过 evidence 校验。 保证“起泡丰富”“一瓶可用一至两个月”等自然语言字段可以被抽出，又不会幻觉。
SKU 从规格字段直接结构化为数组。 避免本地模型输出 {'款式': 'xxx'} 这种不可展示的字符串。

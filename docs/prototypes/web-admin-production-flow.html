新店铺接入主流程

运营从这里完成新店铺授权、商品同步、知识上线、no-send 验收，最后才允许启用 AI。

流程原则： 未识别真实 PDD 店铺 ID / mall_id 前，商品同步、知识发布、AI 启用、worker 启用全部阻断。
运营提示：

远程浏览器登录只用于用户本人完成 PDD 登录、短信验证码、滑块、扫码或安全验证。系统只保存加密授权，不保存密码。

1
填写店铺信息
店铺名称、PDD 账号、负责人。密码只用于本次登录。
2
远程浏览器登录
在 noVNC 窗口完成平台验证，不绕过验证码。
3
绑定真实店铺 ID
自动解析 mall_id；失败时允许人工绑定并审计。
4
同步商品
只读拉取商品列表和详情，写入本地商品知识。
5
发布知识
商品人工知识和 SOP 发布版本并真实索引。
6
no-send 验收
验证价格、规格、用法、售后、敏感和转人工。
7
启用 AI
Checklist 通过后，二次确认启用配置。

店铺管理

接入完成后，日常运营从店铺管理进入。第一期不允许删除店铺，只允许归档。

生产入口
模块 运营可见内容 允许操作 阻断规则
店铺列表 真实 shop_id、店铺名称、授权状态、商品同步状态、知识状态、AI 状态、worker 只读状态 进入详情、重新授权、同步商品、进入知识中心、进入试聊、归档 没有真实 shop_id 时显示“身份待绑定”，不允许正式业务操作
店铺详情 授权状态、最近同步任务、商品覆盖率、active 知识版本、人工锁数量、审计记录 清除授权、关闭 AI、重新同步、查看审计 清除授权、关闭 AI、归档必须二次确认
归档店铺 归档原因、操作者、归档时间 归档，不物理删除 归档前必须关闭 AI，并确认不再接收运营操作
危险操作必须拆开：清空接入流程不等于清除授权；清除授权不等于删除店铺；归档不等于物理删除。

商品同步

使用加密授权读取 PDD 商品列表和详情，写入本地 product_knowledge，不发送 PDD 消息。

只读 PDD

同步前检查

  • shop_auth 有效
  • 真实 mall_id 已绑定
  • 没有 remote-* 正式 shop_id
  • 当前店铺未归档

同步过程

  • 创建 product_sync_job
  • 拉取商品列表
  • 逐个拉取详情
  • 记录成功、失败、跳过

同步后展示

  • 商品总数
  • 价格覆盖
  • 规格覆盖
  • 失败商品和重试入口
商品同步成功后，店铺接入页必须能恢复最近一次同步任务和覆盖率，不能因为跳转页面而丢失状态。

商品知识上线

PDD 原始商品数据只读，运营只编辑人工补充知识。发布后真实索引，索引成功后生效。

真实索引
1. 编辑人工知识
补充卖点、用法、禁忌、售后口径、FAQ、客服话术。PDD 原始字段只读展示。
草稿
2. 保存草稿
只保存运营编辑内容，不影响 AI 当前知识。
不生效
3. 发布版本
生成版本快照，自动创建真实索引任务。
待索引
4. 豆包 embedding
调用服务器全局 Doubao API Key 生成向量，写入 pgvector。
真实索引
5. 生效切换
索引成功后才切换 active version。失败时旧版本继续生效。
Active
生产 UI 不展示 Fake 索引。Fake 只能保留在测试环境或自动化测试，不作为运营功能入口。

SOP 管理

SOP 与商品人工知识走同一套上线机制：草稿、发布、真实索引、生效、归档。

需修复交互

左侧 SOP 列表

  • 按店铺和业务场景筛选
  • 显示状态：草稿、待索引、索引中、已生效、索引失败、已归档
  • 点击一条 SOP 后，右侧编辑器明确加载该内容
  • 新建 SOP 必须打开清晰表单，不能看起来无反应

右侧 SOP 编辑器

  • 显示当前正在编辑的 SOP 名称
  • 未选择时显示空状态
  • 必填：店铺、场景、标题、正文
  • 发布后自动真实索引，成功后 active

接入验收与启用 AI

启用 AI 前必须完成 checklist。启用 AI 只改配置，不直接启动 worker，不发送 PDD。

二次确认
检查项 通过条件 失败时前端展示 是否阻断启用 AI
店铺授权有效 shop_auth valid，真实 shop_id 已绑定 请重新授权或绑定真实店铺 ID 是
商品同步完成 最近同步任务成功或部分成功，商品总数大于 0 请先同步商品并处理失败项 是
知识索引生效 商品知识或 SOP 至少存在 active version 请发布知识并等待真实索引成功 是
no-send 验收 价格、规格、用法、物流、售后、敏感、转人工测试通过 请打开试聊调试完成验收 是
人工锁管理可用 Human Locks API 正常，按 shop_id 隔离 人工接管管理不可用，不能上线 是
Worker 状态 只读展示，不自动启动 当前版本不自动管理 worker 否，警告
启用 AI 弹窗文案：开启后，系统可能会对真实买家消息自动回复。请确认已完成商品同步、知识索引、试聊验证和人工锁检查。

错误处理与安全标准

所有失败都要让运营知道“为什么失败、能不能重试、下一步做什么”。

上线必备

标准错误结构

  • error_type：机器可识别错误类型
  • error_summary：中文错误摘要
  • trace_id：便于排查
  • retryable：是否可重试
  • next_action：下一步处理建议

敏感信息边界

  • 前端不展示 cookie/token/password
  • 日志不打印授权明文
  • 文档和提交不包含真实凭证
  • accounts.cookies 不写明文
生产验收重点：页面不是“看起来能点”，而是每个按钮都有明确后端能力、失败提示、阻断规则和审计记录。

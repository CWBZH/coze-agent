AI 客服运营后台

登录后进入真实运营工作台

用一个清晰的鉴权入口保护店铺接入、知识库、链路观测和 Worker 控制。 后台默认不发送真实 PDD 消息，生产发送由环境开关和店铺状态共同控制。

会话鉴权 登录成功后写入 HttpOnly 会话 Cookie，刷新页面仍保持登录。
运营身份 第一期只区分后台管理员，不做复杂多用户权限。
安全边界 密码和 token 不回显，接口统一返回中文错误和 trace_id。
退出闭环 右上角退出后清除会话并回到登录页。
示例页仅用于确认视觉和流程，不会写入真实项目鉴权逻辑。

后台登录

请输入运营后台账号。生产环境建议只允许内网或固定 IP 访问。

会话保护
忘记密码
失败限制 连续失败 5 次后临时锁定，防止撞库。
接口保护 所有 `/api/*` 接口统一校验会话。
审计记录 记录登录成功、失败、退出和过期事件。
建议落地流程
  1. 访问后台任意页面，未登录时自动跳转到 `/login`。
  2. 登录成功后后端签发 HttpOnly Cookie，前端跳回原访问页面。
  3. 页面右上角显示当前管理员和退出按钮。
  4. 会话过期时接口返回 401，前端保留当前 URL 并跳回登录页。

5. 上线启用

把“启用 AI 配置”和“启动 Worker”分成两个动作，避免误以为启用 AI 就会立即发送 PDD 消息。

启用 AI 配置 未启用 只改变店铺 AI 配置，不启动 Worker，不发送 PDD。
Worker 控制 未运行 Web 后台只下发指令，Worker Manager 执行启动、停止和重启。
PDD_SENDING_ENABLED 必须单独打开；上线前默认保持关闭，真实发送开启后每条回复都要进入链路观测。

# Web Admin 前端必要功能缺口分析

## 1. 结论

当前 Web Admin 已具备内部试运营所需的核心页面：数据总览、店铺、商品知识、知识中心、人工锁、试聊调试、调试日志和系统设置。

它已经适合内部运营人员做 no-send 调试、知识维护和单店灰度前检查。公网部署、多店全量和商家开放后台仍需要补权限、审计、部署和同步能力。

## 5. 逐页审计

### 数据总览

- 当前功能：展示总体指标、安全状态、告警和最近活动。
- 用户是否看得懂：已增加中文说明。
- 是否缺关键操作：缺真实趋势图和 worker 状态。
- 是否建议发布前补：内部试运营不阻塞，灰度前建议补真实指标。

### 店铺管理

- 当前功能：查看店铺列表和详情。
- 用户是否看得懂：已增加中文说明，并引导新店进入“店铺接入”。
- 是否缺关键操作：缺从店铺详情直接跳转接入任务和同步任务。
- 是否建议发布前补：单店内部不阻塞，多店运营前建议补。

### 商品知识

- 当前功能：真实商品数据、覆盖率、详情、chunks、RAG debug，并可从店铺接入流程启动商品同步。
- 用户是否看得懂：已中文化主说明和按钮。
- 是否缺关键操作：缺批量导入、outdated 检测、字段来源高亮增强。
- 是否建议发布前补：不阻塞内部试运营。

### 知识中心

- 当前功能：SOP、商品人工知识、版本、索引任务、验证入口。
- 用户是否看得懂：已增加发布不等于生效、Fake/Real index 提示。
- 是否缺关键操作：缺版本 diff、rollback UI、批量导入。
- 是否建议发布前补：内部试运营不阻塞，灰度前建议补 outdated 检测。

### 人工锁管理

- 当前功能：按店铺查询、单条解除、按会话解除、店铺内批量解除。
- 用户是否看得懂：已中文化并补充安全提示。
- 是否缺关键操作：缺真实业务原因统计和操作日志列表。
- 是否建议发布前补：不阻塞。

### 试聊调试

- 当前功能：facade/real provider profiles、商品卡片、Trace Panel、no-send。
- 用户是否看得懂：已中文化配置、试聊和服务状态。
- 是否缺关键操作：缺常用测试用例模板、一键带入知识中心版本参数。
- 是否建议发布前补：不阻塞。

### 调试日志

- 当前功能：查看 trace 列表和详情。
- 用户是否看得懂：已增加中文说明。
- 是否缺关键操作：缺分页、筛选联动、导出、错误聚合。
- 是否建议发布前补：内部试运营不阻塞。

### 系统设置

- 当前功能：查看 provider 安全摘要和 no-send 状态。
- 用户是否看得懂：已中文化。
- 是否缺关键操作：缺登录权限、配置检测历史、服务健康详情。
- 是否建议发布前补：公网部署前必须补登录权限。

## 6. 发布建议

第一阶段建议发布范围：

- 内部试运营：可以。
- 单店灰度：可以，但建议先补启动脚本和基础运行指标。
- 多店全量：暂缓，建议补权限、店铺接入、worker 管理和数据同步/outdated 检测。
- 公网开放：暂缓，登录权限是 P0。

## 8. T204-B 店铺接入 MVP 更新

当前“店铺接入”页面已经收敛为远程浏览器登录唯一入口，支持：

- 创建 PDD 登录会话。
- 轮询登录状态。
- 通过 noVNC 远程浏览器完成短信验证码、滑块、扫码或安全验证。
- 取消登录会话。
- 登录成功后通过 CDP 读取登录态并保存加密授权状态。
- 页面提示“不会发送 PDD 消息”和“尚未启用 AI 自动回复”。
- 登录成功后进入商品同步步骤。

仍未完成的前端必要功能：

| 优先级 | 功能 | 当前状态 | 影响 |
| --- | --- | --- | --- |
| P0 | 登录权限/用户隔离 | 未实现 | 公网部署阻塞 |
| P1 | 接入验收 checklist | 已实现基础版 | 后续补自动 no-send runner 和真实 worker 状态 |
| P1 | onboarding checklist | 已实现基础版 | 后续补权限、audit 查询页和 worker 运行侧读取 AI enabled 状态 |
| P1 | worker 启停和连接状态管理 | 未集成 | 多店运营前建议补齐 |
| P2 | 多并发远程浏览器会话管理 | 当前 MVP 面向单会话/少量会话 | 多用户并发接入前需要 |

结论：T204-B/T204-C/T204-D 后台接入入口已经具备登录授权、商品同步、接入验收和 AI 配置启用 MVP。它仍不能视为完整商家自助接入产品，因为还缺登录权限、worker 运行侧读取 AI enabled 状态、自动 no-send 验收 runner 和真实 worker 状态管理。

# 商品属性知识结构化与召回策略开发计划

## 1. 背景问题

近期日志暴露的问题不是单一关键词缺失，而是执行链路边界不清：

```text
用户问商品属性
-> 粗意图识别为 pre_sale
-> 因为没有明确 goods_id 或策略判断不足
-> 进入商品列表召回
-> 把“使用时长、起泡、气泡、这支”等属性词或指代词当成商品检索词
-> 注入候选商品列表
-> 生成“推荐这款”话术
-> 覆盖 ProductMemory
```

典型错误：

```text
使用时长有吗 -> keywords=['使用', '时长'] -> 未找到款式
起泡多吗 -> 召回洗面奶 -> 回复推荐商品
这支洗面奶气泡多吗 -> 重新召回 3 个商品 -> 覆盖当前锁定商品
```

核心结论：

```text
pre_sale 只是业务大类，不能直接决定检索方式。
商品属性问答必须走当前商品知识，不应触发商品列表召回。
商品同步阶段必须把属性知识结构化持久化，否则运行时只能在文本里猜。
```

## 2. 目标架构

新增一层 `retrieval_policy`，把“意图识别”和“检索执行”解耦。

```text
用户问题
-> intent: pre_sale / recommend / logistics / after_sales / general / redline
-> sub_intent: usage_duration / usage_method / foaming / ingredient / price / sku_spec
-> entity_scope: current_product / product_candidates / shop / unknown
-> retrieval_policy: current_product / product_candidates / clarify_product / shop_knowledge / none
-> retriever 按策略取数
-> generator 按结构化属性或知识上下文生成
```

最终边界：

```text
找商品、推荐商品 -> product_candidates
问当前商品属性 -> current_product
没有商品上下文但在问属性 -> clarify_product
售后/物流/闲聊 -> 对应专用知识或固定规则
```

### 5.2 规则抽取核心代码

```python
def _extract_attributes_by_rules(self, list_product, detail_product):
    goods_name = str(list_product.get("goods_name") or "")
    specs = detail_product.get("specifications", []) or []
    text = f"{goods_name}\n{json.dumps(specs, ensure_ascii=False)}"

    attrs = dict(DEFAULT_PRODUCT_ATTRIBUTES)
    sources = {}

    def set_attr(key, value, source, confidence, evidence):
        if value and not attrs.get(key):
            attrs[key] = value
            sources[key] = {
                "source": source,
                "confidence": confidence,
                "evidence": evidence[:200],
            }

    category_rules = {
        "洗面奶": ["洗面奶", "洁面", "洁面乳"],
        "香水": ["香水", "香氛", "喷雾"],
        "洗脸巾": ["洗脸巾", "棉柔巾", "柔纸巾"],
        "湿敷棉": ["湿敷棉", "化妆棉", "棉片"],
    }
    for category, terms in category_rules.items():
        if any(term in text for term in terms):
            set_attr("category", category, "rule", 0.95, goods_name)
            break

    quantity_match = re.search(r"\d+\s*(瓶|支|盒|包|片|抽|ml|g|克)", text, flags=re.I)
    if quantity_match:
        set_attr("sku_summary", quantity_match.group(0), "rule", 0.9, quantity_match.group(0))

    fragrance_terms = ["茉莉", "栀子", "桂花", "玫瑰", "白茶", "原味"]
    matched_fragrance = [term for term in fragrance_terms if term in text]
    if matched_fragrance:
        set_attr("fragrance", "、".join(matched_fragrance), "rule", 0.85, goods_name)

    age_match = re.search(r"(\d+\s*岁以上|儿童|婴儿|宝宝|成人|孕妇)", text)
    if age_match:
        set_attr("suitable_age", age_match.group(0), "rule", 0.85, age_match.group(0))

    return attrs, sources
```

### 5.4 合并规则

```python
def _merge_product_attributes(self, rule_attrs, rule_sources, llm_attrs, llm_sources):
    attrs = dict(DEFAULT_PRODUCT_ATTRIBUTES)
    sources = {}

    for key in attrs:
        rule_value = rule_attrs.get(key)
        llm_value = llm_attrs.get(key)
        rule_conf = (rule_sources.get(key) or {}).get("confidence", 0)
        llm_conf = (llm_sources.get(key) or {}).get("confidence", 0)

        if rule_value and rule_conf >= 0.8:
            attrs[key] = rule_value
            sources[key] = rule_sources[key]
        elif llm_value and llm_conf >= 0.65:
            attrs[key] = llm_value
            sources[key] = llm_sources[key]
        else:
            attrs[key] = "" if key not in {"effect", "warnings"} else []
            sources[key] = DEFAULT_ATTRIBUTE_SOURCE

    return attrs, sources
```

```python
def _render_product_context(self, list_product, detail_product, attrs):
    lines = [f"# {list_product.get('goods_name')}"]
    lines.append(f"价格: {list_product.get('price') or ''}")
    lines.append(f"规格: {attrs.get('sku_summary') or ''}")
    lines.append(f"类目: {attrs.get('category') or ''}")
    lines.append(f"成分/材质: {attrs.get('ingredients') or ''}")
    lines.append(f"使用方法: {attrs.get('usage_method') or ''}")
    lines.append(f"使用时长: {attrs.get('usage_duration') or ''}")
    lines.append(f"起泡情况: {attrs.get('foaming') or ''}")
    lines.append(f"适用年龄: {attrs.get('suitable_age') or ''}")
    lines.append(f"适用肤质: {attrs.get('skin_type') or ''}")
    lines.append(f"香味: {attrs.get('fragrance') or ''}")
    lines.append(f"功效: {'、'.join(attrs.get('effect') or [])}")
    lines.append(f"注意事项: {'、'.join(attrs.get('warnings') or [])}")
    return "\n".join(line for line in lines if line.strip())
```

```python
def _classify_sub_intent(self, query: str) -> str:
    q = self._clean_user_query(query).lower()

    if any(term in q for term in ("使用时长", "用多久", "能用多久", "可以用多久", "用几天", "能用几天")):
        return SubIntentType.USAGE_DURATION

    if any(term in q for term in ("怎么用", "如何用", "什么时候用", "用法", "一天几次")):
        return SubIntentType.USAGE_METHOD

    if any(term in q for term in ("起泡", "泡沫", "气泡", "泡泡", "绵密", "丰富吗")):
        return SubIntentType.FOAMING

    if any(term in q for term in ("成分", "含不含", "酒精", "香精", "材质")):
        return SubIntentType.INGREDIENT

    if any(term in q for term in ("多少钱", "价格", "几块", "几元", "优惠")):
        return SubIntentType.PRICE

    if any(term in q for term in ("几片", "多少片", "几瓶", "规格", "容量", "多少ml")):
        return SubIntentType.SKU_SPEC

    if any(term in q for term in ("推荐", "有没有", "哪款", "哪种", "想买", "换一款")):
        return SubIntentType.PRODUCT_DISCOVERY

    return SubIntentType.NONE
```

### 7.2 召回策略决策函数

```python
ATTRIBUTE_SUB_INTENTS = {
    SubIntentType.USAGE_DURATION,
    SubIntentType.USAGE_METHOD,
    SubIntentType.AGE_SAFETY,
    SubIntentType.SKU_SPEC,
    SubIntentType.PRICE,
    SubIntentType.INGREDIENT,
    SubIntentType.FOAMING,
    SubIntentType.PRODUCT_ATTRIBUTE,
}

def _resolve_retrieval_policy(self, *, query, intent, sub_intent, goods_id, product_memory):
    current_goods_id = goods_id or product_memory.get("goods_id")

    if intent == IntentType.LOGISTICS:
        return RetrievalPolicy.SHOP_KNOWLEDGE, current_goods_id, "shop"

    if intent in {IntentType.AFTER_SALES, IntentType.REDLINE, IntentType.GENERAL}:
        return RetrievalPolicy.SHOP_KNOWLEDGE, current_goods_id, "shop"

    if sub_intent in ATTRIBUTE_SUB_INTENTS:
        if current_goods_id:
            return RetrievalPolicy.CURRENT_PRODUCT, current_goods_id, "current_product"
        return RetrievalPolicy.CLARIFY_PRODUCT, None, "unknown"

    if intent == IntentType.RECOMMEND:
        return RetrievalPolicy.PRODUCT_CANDIDATES, current_goods_id, "product_candidates"

    if sub_intent == SubIntentType.PRODUCT_DISCOVERY:
        return RetrievalPolicy.PRODUCT_CANDIDATES, current_goods_id, "product_candidates"

    if self._is_product_followup_query(query) and current_goods_id:
        return RetrievalPolicy.CURRENT_PRODUCT, current_goods_id, "current_product"

    if intent == IntentType.PRE_SALE:
        return RetrievalPolicy.CLARIFY_PRODUCT, current_goods_id, "unknown"

    return RetrievalPolicy.NONE, current_goods_id, "unknown"
```

## 8. Retriever 核心代码

### 8.1 node_retriever 改为按策略执行

```python
def node_retriever(self, state: CustomerServiceState) -> CustomerServiceState:
    intent = state.get("current_intent", IntentType.UNKNOWN)
    sub_intent = state.get("sub_intent", SubIntentType.NONE)
    policy = state.get("retrieval_policy", RetrievalPolicy.NONE)
    shop_id = state.get("shop_id")
    goods_id = state.get("locked_goods_id")
    query = state.get("user_query", "")
    session_id = state.get("session_id", "")

    if policy == RetrievalPolicy.CURRENT_PRODUCT:
        knowledge_context = self._fetch_current_product_attribute_context(
            shop_id=shop_id,
            goods_id=goods_id,
            sub_intent=sub_intent,
            query=query,
            session_id=session_id,
        )

    elif policy == RetrievalPolicy.PRODUCT_CANDIDATES:
        knowledge_context = self._fetch_product_list_for_recommendation(
            shop_id=shop_id,
            query=query,
            session_id=session_id,
        )

    elif policy == RetrievalPolicy.CLARIFY_PRODUCT:
        knowledge_context = "【澄清提示】：用户在问商品属性，但当前没有明确商品上下文。请询问用户具体是哪款商品。"

    elif policy == RetrievalPolicy.SHOP_KNOWLEDGE:
        knowledge_context = self._fetch_shop_knowledge_or_rule(intent, query, shop_id)

    else:
        knowledge_context = "未找到相关知识"

    logger.info(
        f"[Retriever] policy={policy}, intent={intent}, sub_intent={sub_intent}, "
        f"goods_id={goods_id}, context_len={len(knowledge_context)}"
    )

    return {**state, "knowledge_context": knowledge_context}
```

```python
def _fetch_current_product_attribute_context(self, *, shop_id, goods_id, sub_intent, query, session_id):
    product = self._get_product_by_goods_id(shop_id, goods_id)
    if not product:
        return f"【当前商品】：未找到商品ID {goods_id} 的本地知识。"

    attrs = self._load_json(product.attribute_json, default={})
    sources = self._load_json(product.attribute_source_json, default={})

    field = self._sub_intent_to_attribute_field(sub_intent)
    value = attrs.get(field) if field else ""
    source = sources.get(field) or {}

    if value:
        return self._format_attribute_context(
            product=product,
            field=field,
            value=value,
            source=source,
        )

    return self._format_missing_attribute_context(
        product=product,
        field=field,
        sub_intent=sub_intent,
    )
```

```python
def _build_attribute_reply(self, query, knowledge, sub_intent):
    if "【属性命中】" in knowledge:
        goods_name = self._extract_context_value(knowledge, "商品名称")
        field = self._extract_context_value(knowledge, "属性字段")
        value = self._extract_context_value(knowledge, "属性值")

        if sub_intent == SubIntentType.USAGE_DURATION:
            return f"这款可用时长参考：{value}。"
        if sub_intent == SubIntentType.FOAMING:
            return f"这款起泡情况是：{value}。"
        if sub_intent == SubIntentType.INGREDIENT:
            return f"这款成分信息是：{value}。"
        return f"这款{field}是：{value}。"

    if "【属性缺失】" in knowledge:
        if sub_intent == SubIntentType.USAGE_DURATION:
            return self._variant_reply([
                "页面暂时没有明确标注可用多久，实际会和每次用量有关哦。",
                "详情里没有写具体能用几天，建议按页面规格和每次用量参考。",
                "这个没有明确标注使用周期，主要看每次用量哦。",
            ])
        if sub_intent == SubIntentType.FOAMING:
            return "页面没有明确标注起泡情况，建议以详情页实际说明为准哦。"
        return "页面暂时没有明确标注这项信息，建议按商品详情页说明为准哦。"

    return None
```

```python
def _fetch_product_list_for_recommendation(self, shop_id, query="", session_id=""):
    clean_query = self._clean_user_query(query)
    sub_intent = self._classify_sub_intent(clean_query)

    if sub_intent in ATTRIBUTE_SUB_INTENTS:
        logger.info(
            f"[Retriever] 属性问题禁止商品列表召回: sub_intent={sub_intent}, query='{clean_query[:30]}'"
        )
        return "【澄清提示】：这是商品属性问题，不应召回商品列表。"

    # existing candidate retrieval...
```

这条是保险，不是主逻辑。主逻辑仍然由 `retrieval_policy` 控制。

## 11. ProductMemory 更新规则

当前问题之一是属性追问会覆盖 `ProductMemory`。规则应改为：

```text
只有 PRODUCT_CANDIDATES 策略允许更新 ProductMemory。
CURRENT_PRODUCT / CLARIFY_PRODUCT / SHOP_KNOWLEDGE 不允许更新。
```

核心代码：

```python
def _format_product_candidates_context(self, products, keywords, session_id, allow_memory_update=True):
    # format context...
    if allow_memory_update and products:
        self._set_product_memory(session_id, selected_memory)
```

调用处：

```python
allow_memory_update = state.get("retrieval_policy") == RetrievalPolicy.PRODUCT_CANDIDATES
```

## 13. 最终工程原则

```text
intent 决定业务大类。
sub_intent 决定问题槽位。
retrieval_policy 决定查什么数据。
attribute_json 负责商品属性问答。
product_search_terms 只负责找商品。
extracted_content 只作为 LLM 兜底上下文。
ProductMemory 只在真正推荐商品时更新。
```

这套设计的关键不是继续堆关键词，而是把“问商品属性”和“找商品推荐”从数据源和执行策略上彻底隔离。
